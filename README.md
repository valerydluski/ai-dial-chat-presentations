## Reproduce the bundle

Run commands from this directory. Dependencies belong here, not in `ai-dial-chat`. Full source and rendering checks need the adjacent source checkout, the separately installed official skill, LibreOffice and fonts; see PUBLISHING.md. The website build only needs Python 3.10+.

```bash
npm ci
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm run generate
npm run generate -- libs/attachment-canvas
npm run render
npm run render -- overview
npm run check:examples
npm run check
npm run index
npm run check:resume
npm run check:bundle
npm run site:build
npm run site:check
```

`npm run generate -- <id>` accepts `overview`, `apps/chat`, or any `libs/<slug>`. The generator reads the structured content under `content/decks/`; editing these JSON files is the supported way to revise wording. Every slide has a stable ID.

Generation skips outputs with unchanged inputs and protects PPTX files whose hash differs from the last generated artifact. Rendering also skips unchanged previews and protects edited preview files; npm run index protects manually edited generated indexes. It never imports changes from a manually edited PPTX into JSON. Save manual variants under a new filename. The manifest records per-deck progress so an interrupted run can continue. The authoring helpers in `src/author-*.py` are provenance tools; they are not needed for regeneration.

Rendering uses the Anthropic LibreOffice wrapper to convert the actual PPTX to PDF, then PyMuPDF at 150 dpi to produce PNGs. Individual images, PDFs, contact sheets and an HTML viewer are in each preview directory. The optional local macOS Apple Silicon renderer is `tools/LibreOffice.app`; on other platforms install LibreOffice and make `soffice` available on PATH. Poppler/pdftoppm was unavailable; PyMuPDF is the explicit PDF-rasterization substitute.

Arial and Courier New are used. The portable renderer resolves these installed macOS fonts through local symlinks; no font files are redistributed. Run `.venv/bin/python src/setup-fonts.py` if those links need rebuilding. The PDF audit verifies ArialMT, Arial-BoldMT and CourierNewPSMT. Other machines need their own licensed fonts.
